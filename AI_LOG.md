## 3. My Own Work and Decisions

I actively participated in development by writing and modifying code, testing functionality and identifying problems.

For example, I discovered a CSS layout problem on the checkout page and investigated the differences between `globals.css` and `checkout.module.css`.

I also decided to improve the shopping cart by adding quantity controls to product detail pages, allowing users to remove all quantities of a product, and making product images and titles clickable in the cart.

I tested these changes locally and on the deployed website.

## 4. How I Verified AI Suggestions

I did not assume that every AI suggestion was correct.

I checked the code in VS Code, tested the functionality in the browser and used the terminal to identify errors.

My workflow was usually:

1. Identify a problem or feature.
2. Ask AI for an explanation or suggestion.
3. Make a small code change.
4. Test the result.
5. Continue only when the change worked.

This helped me understand the code and avoid making too many changes at once.

## 5. Limitations and Challenges

Some concepts were difficult for me, especially React state, props, Context API and TypeScript.

AI explanations helped me understand how these concepts work together.

I also learned that AI suggestions must be checked against the actual project code because function names, component structures and CSS rules can differ.

## 6. Reflection on AI Usage

Using AI helped me make progress while learning JavaScript frameworks.

The most useful approach was to work in small steps instead of copying large amounts of code without understanding them.

I learned more by testing changes, investigating errors and asking questions about why the code worked.

AI was a development and learning tool, but I remained responsible for reviewing, testing and submitting the project.
